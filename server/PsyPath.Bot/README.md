# PsyPath.Bot — Психея в Telegram

Telegram-бот с тем же функционалом, что у обычного пользователя в приложении. Работает через тот же API, поэтому аккаунт, прогресс, серия и результаты опросников общие: прошёл урок в боте — он отмечен и в приложении.

| В приложении | В боте |
|---|---|
| вход и регистрация | кнопки «ВОЙТИ» / «РЕГИСТРАЦИЯ»; сообщение с паролем бот сразу удаляет |
| знакомство и цель на день | при первом входе, у админа пропускается |
| вкладка «Вопросы» (путь) | «Путь» — юниты, ▶ текущий, ✓ пройден, ○ открыт, ▒ закрыт |
| урок | «▶ Урок» — одно сообщение, которое бот правит: выбор, верно/неверно, кейс, пропуск, пары, порядок; ошибка повторяется в конце, рейтинг и XP — по тем же правилам |
| опросники | «Опросники» — вопросы, «назад», результат с описанием, +15 XP, запись в историю |
| справочник | «Справочник» или просто напиши слово — бот найдёт термин |
| профиль | «Профиль» — уровень, рейтинг, XP, серия, точность, история, достижения; цель дня, сброс прогресса, выход, удаление аккаунта |

Админ-панели в боте нет — она в приложении. Задания «введи ответ» и «кейс с ветвлением» тоже есть только в приложении: бот их пропускает.

## Создать бота

1. В Telegram открой @BotFather → `/newbot` → имя и username.
2. Он пришлёт токен вида `123456:ABC…`. Это секрет: не выкладывай его на GitHub и никому не пересылай.

## Запуск на ПК

1. Скопируй `bot.env.example` в `bot.env` (в этой же папке) и впиши `BOT_TOKEN`. `PSYPATH_API_URL` оставь `http://217.71.129.139:6354`.
2. В Visual Studio выбери проект `PsyPath.Bot` и нажми F5, или в терминале:

```powershell
dotnet run --project server\PsyPath.Bot
```

В консоли появится `@имя_бота v1.0 запущен`. Пока окно открыто, бот отвечает.

## Запуск на сервере

С сервера НГТУ `api.telegram.org` недоступен (соединение висит до таймаута), поэтому там бот работает только через прокси: `BOT_PROXY=socks5://host:port` или `http://host:port`. Без прокси запускай его на ПК или любом другом сервере, откуда открывается Telegram. Команды — в `server/DEPLOY.md`, раздел «Telegram-бот».

## Если Telegram закрыт в сети

Бот ходит в Telegram по HTTPS (`api.telegram.org`). MTProto-прокси вроде TG WS Proxy работают только для приложения Telegram, боту они не помогают. Варианты:

- VPN на весь компьютер — `BOT_PROXY` и `BOT_API_URL` пустые;
- SOCKS5 или HTTP-прокси — `BOT_PROXY`;
- свой Cloudflare Worker, который пересылает запросы в Telegram, — `BOT_API_URL`.

Worker: dash.cloudflare.com → Workers & Pages → Create → Hello World → Edit code, вставить и Deploy:

```js
export default {
  async fetch(req) {
    const url = new URL(req.url);
    url.hostname = "api.telegram.org";
    return fetch(new Request(url, req));
  }
};
```

Его адрес (`https://имя.аккаунт.workers.dev`) — в `BOT_API_URL`. Токен проходит через Worker, поэтому только свой: чужие «зеркала» Telegram API не использовать.

## Настройки

| Переменная | Что | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather | — (обязательно) |
| `PSYPATH_API_URL` | адрес API | `http://psypath_api:5080` |
| `BOT_PROXY` | прокси до Telegram: `socks5://` или `http://` (MTProto-прокси не подходит) | нет |
| `BOT_API_URL` | свой адрес вместо `https://api.telegram.org`, например Cloudflare Worker | нет |
| `BOT_TZ` | часовой пояс для серии и цели дня | `Asia/Novosibirsk` |
| `BOT_DATA` | папка с `sessions.json` — входы пользователей (токены API) | `data` |

Переменная окружения важнее строки в `bot.env`.

## Устройство

| Файл | Что |
|---|---|
| `Program.cs` | настройки, запуск опроса Telegram |
| `PsyBot.cs` | экраны: меню, вход, путь, профиль, справочник; разбор кнопок |
| `LessonRun.cs` | прохождение урока |
| `QuizRun.cs` | прохождение опросника и текст результата |
| `Game.cs` | правила: рейтинг, уровни, XP, серия, достижения, подсчёт опросников — как `AppState` приложения |
| `PsyApi.cs` | запросы к API |
| `ContentStore.cs` | уроки, опросники, справочник с сервера; правки из админки подхватываются за 2 минуты |
| `Sessions.cs` | чаты и их вход |

Модели (`Models.cs`) не скопированы, а подключены из приложения: поменяешь модель — она поменяется и у бота.

Ограничение API: не больше 10 входов и регистраций в минуту с одного адреса. У бота адрес один на всех, так что при наплыве новых пользователей кто-то увидит «Слишком много попыток, подожди минуту».

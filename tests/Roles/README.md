# Проверка роли менеджера

Из `content`: `dotnet run --project tests/Roles/Roles.csproj -c Release` с SDK .NET 9.

36 проверок выполняются через временный API на `127.0.0.1` и настоящий middleware авторизации.
Используются исходные маршруты, обработчик назначения роли и свойства доступа клиента.
Вместо PostgreSQL подключено хранилище тестовых аккаунтов, вместо JWT — тестовая аутентификация;
запросы к рабочему серверу и реальной базе не выполняются.

Проверяются доступ менеджера к контенту, запрет пользователей/статистики/смены ролей,
назначение и отзыв администратором, устаревшие claims, блокировка и удалённые аккаунты.
Для чтения данных используются probes после настоящей авторизации; изменение роли проходит настоящий endpoint.
Положительный вызов контента дополнительно проходит реальную проверку тела запроса.

Для запуска на реальном сервере сначала применить `server/db/003_manager.sql` от владельца базы,
затем обновить API и приложение. Миграция этими проверками не применяется.

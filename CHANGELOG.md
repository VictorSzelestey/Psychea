# История изменений

## 1.5.0 — 2026-11-10

### Новое
- Раздел «Социальная психология»: 5 уроков, 40 заданий. Темы: предмет социальной психологии, виды групп, роли и власть, сплочённость и лидерство, социализация личности.
- В справочник добавлена 51 статья; всего 72. Прежние статьи и уроки сохранены.
- При первом знакомстве можно выбрать роль: «Студент», «Психолог» или «Просто интересно». Выбранная роль сохраняется в прогрессе и показывается в профиле.
- Журнал ошибок в `.txt`: время, версия приложения, модель телефона, версия Android, открываемые экраны, жизненный цикл приложения, номер вопроса без выбранного ответа, ошибки API, исключения со стеком и предупреждения о нехватке памяти.
- Записываются необработанные исключения .NET и Android runtime, необслуженные исключения фоновых задач, предупреждения и ошибки MAUI.
- На Android 11+ при следующем запуске журнал дополняется системной причиной предыдущего завершения; при наличии — системным trace зависания (ANR) или native crash.
- Настройки → Диагностика → «Отправить журнал»: последние журналы объединяются в один `.txt`, который можно передать разработчику.
- Журналы хранятся в `Android/data/com.psypath.app/files/Psychea/logs`; при недоступности внешней памяти — во внутренней папке приложения. Хранятся последние 10 файлов примерно по 1 МБ.
- Записи сразу сбрасываются на диск. Пароли и токены фильтруются; тела запросов и ответов API и ответы на опросники не записываются. Ошибка записи журнала не прерывает работу приложения.

### Исправлено
- «Да» и «Нет» в опросниках оформлены одинаково: цвет больше не подсказывает ответ.
- Выбранный ответ отмечается одинаковым цветом и галочкой, а состояние выбора доступно экранному диктору.
- Выбор ответа можно изменить; ответ сохраняется и следующий вопрос открывается только по кнопке «Дальше».
- Кнопка «Дальше» отключена до выбора ответа. Защита от повторных нажатий во время перехода и событий от предыдущего вопроса предотвращает пропуск вопросов и повторное сохранение ответа.
- Рейтинг показывает 10 пользователей вместо 50; своё место видно и за пределами десятки.
- Лимит топ-10 установлен в API и приложении: новая версия приложения показывает десять строк и со старым сервером.
- В заданиях «Соедини пары» можно свободно выбирать и менять пары до проверки; один правый вариант связывается только с одним левым.
- Пары проверяются общей кнопкой «Проверить» после выбора всех пар; немедленная проверка и красная подсветка ошибочного соединения убраны.

### Релиз и проверки
- Изменения из архива разработчика импортированы в alt2 и объединены с исправлениями из alt, затем включены в main.
- Версия приложения и `releases/version.json` повышена с 1.4 / 1.4.0 до 1.5.0, код версии Android — с 5 до 6.
- Подписанный APK опубликован в `releases/Psychea.apk` ветки main и в GitHub Release `v1.5.0`. Идентификатор `com.psypath.app` и сертификат подписи сохранены для обновления поверх 1.4.
- В описание обновления добавлен список изменений 1.5.0. Публичные `version.json` и APK проверены: HTTP 200, версия и SHA-256 скачанного APK совпадают с релизом.
- Сборки Android-приложения и API завершились успешно. Добавлены и пройдены 8 проверок журнала: недоступная папка и запасной путь, параллельная запись, фильтрация реквизитов, вложенные исключения, ротация, экспорт, ошибка экспорта и сохранение стека при аварийном завершении отдельного процесса.

### Что учитывать
- Новые встроенные уроки и статьи нужно отдельно опубликовать на сервере: серверный контент имеет приоритет над содержимым APK. Развёртывание API и публикация контента в этот выпуск не входили.
- Журнал предназначен для поиска причины случайных падений; сама причина пока не установлена. После сбоя нужно снова открыть приложение, затем отправить журнал из настроек. Системный trace доступен не при каждом завершении.
- Установка обновления поверх 1.4 и работа интерфейса на телефоне пока не проверены; проверены сборка, подпись, версия и источник обновлений.

## 1.4.0 — 2026-11-09

### Новое
- Слон — значок темперамента в итогах тестов «Темперамент» и EPI и в профиле.
- В истории опросников показан твой темперамент с описанием.
- Опросник Айзенка (EPI). У всех появится после публикации администратором.
- Кнопка «Опубликовать для всех» в админке: добавляет на сервер опросники, которые есть в приложении.
- Список изменений в окне обновления.

### Исправлено
- Разделы на главном экране пронумерованы по порядку: после второго идёт третий, а не тринадцатый.
- У разделов показано, сколько уроков пройдено.
- В работе над ошибками задание больше не повторяется дважды за один заход.

# Psychea
Android приложение для изучения психологии в формате уроков и опросников. .NET MAUI

## Карточка «Поделиться» после урока

Кнопка «Поделиться результатом» создаёт отдельный PNG 1200×1360 по присланному макету: бумажный фон, фиолетовые волны, манул с сердцем, XP, точность и изменение рейтинга. Значения берутся из завершённого урока; в работе над ошибками заголовок меняется на «Повтор пройден». Внизу расположен бренд и адрес страницы загрузки приложения.

Рендер находится в `PsyPath/Services/LessonShareCardRenderer.cs`, отправка файла — в `ShareCard.ShareLesson`. Изображение и шрифты входят в пакет приложения, поэтому создание карточки работает без сети. Настройка `SkiaSharp` восстанавливается через NuGet вместе с зависимостями проекта.

Проверить тот же рендер и получить примеры PNG без телефона:

```powershell
dotnet run --project tests/ShareCards/ShareCards.csproj
```

Проверяются реальные значения статистики, отрицательное изменение рейтинга, нули, большие числа, заголовок повтора, PNG и логотипы. Пути созданных изображений выводятся в консоль. Системное окно отправки проверяется отдельно на Android-устройстве.
